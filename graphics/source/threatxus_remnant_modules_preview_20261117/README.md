# Threatxus with Nexus modules — concept preview

Preview-only ImageGen composition of the existing Threatxus hull and the full
Remnant Nexus15-module arrangement, using native cyan/gunmetal insert references.
No hull data, runtime sprite, variants, mission or JAR has been replaced.

The installed remnant_station2_Standard variant supplies3long weapon platforms,
4oval platforms,3armor sections,3shield nodes and2hangars. Placement/pivot
instructions in prompt.txt come from remnant_station2.ship and native child
centers. Generated placement, pixels and scale are approximate, not a native
engine rendering. ImageGen accepts5input paths: Threatxus plus long platform,
oval platform, armor and hangar. Round shield nodes were described in the prompt.

Reference art belongs to Fractal Softworks/the supplied Threatxus composition.
This study keeps the stock module palette; it is not a runtime recolor.
