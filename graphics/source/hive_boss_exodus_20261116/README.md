# Exodus Plague Hive boss concepts

User direction: a third Threat boss based on the installed native Hive Unit,
using the preserved Exodus Plague system. Seek the uncanny, almost-coherent
detail of early image generation. The current exploration is a geoduck-like
shell with a single extension ending in a Bobbit worm head and hooked jaws.

Generated with the built-in image_gen tool; no Midjourney connection or older
Midjourney model was used. Exact prompts are retained beside each version.
Concept masters are preserved without runtime hull, geometry, encounter or
sprite integration. The first Hive-only pass remains for comparison.

- Current concept: [geoduck/Bobbit v2](hive_boss_geoduck_bobbit_v2.png).
- Exact generation prompt: [v2 prompt](hive_boss_geoduck_bobbit_v2.prompt.txt).
- Exact background-cleanup prompt: [cutout prompt](hive_boss_geoduck_bobbit_v2_cutout.prompt.txt).
- First pass: [Hive v1](hive_boss_uncanny_v1.png) and [its prompt](hive_boss_uncanny_v1.prompt.txt).
- [Diable Avionics animation research and proposed rig](../../../docs/HIVE_BOSS_ARTICULATION.md).

The current master is a 1024x1536 RGBA concept with transparent background.
Preserve raw and cleanup attempts. It has not been split into complete
overlapping segment/jaw assets and has no installed animation controller.

Reference `native_threat_hive_reference.png` is an unmodified copy of the
installed Starsector asset `starsector-core/graphics/ships/threat/threat_hive.png`
(212x280). Original Starsector artwork belongs to Fractal Softworks. Generated
variants derive from that reference. Do not treat these as independent original
art or publish the base reference without its applicable terms.

Gautama has returned to native Extraction Protocol. Exodus Plague is now used
by the special Assault Units fabricated by the Threatxus prototype, with its
latest tapered streams and20-second cooldown. These earlier Hive/geoduck
concept masters remain unintegrated.
