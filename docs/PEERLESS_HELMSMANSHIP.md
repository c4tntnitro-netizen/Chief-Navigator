# Peerless training

The standalone **Peerless Skills** mod is optional. Chief Navigator loads and completes its story without it. When Peerless Skills is enabled, completing Menelaus's final Labor debrief grants the Domain Epic title and one Peerless point through its public API. The existing permanent receipt prevents repeat grants. An unavailable optional integration leaves that receipt unclaimed. Menelaus has no separate distinction or training menu.

Train using **Peerless skills...** above vanilla skill reassignment or **Intel > Contacts > [your character] - Peerless training**. SiC uses the contact route. The shared mod manages prerequisites, point spending, skill effects, and refunds.

The other independent story reward comes from finishing Isa's *A Borrowed Name* in Hall of Triumph. Neither story mod requires the other. Isa and Sinni do not offer Peerless training.

Peerless Skills owns the currency, player effects, character-screen icons, skill definitions, artwork, and `AddPeerlessPoint` console command. See its README for the mod API and its native regression checks. No XP progression is installed.
